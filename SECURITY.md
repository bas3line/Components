# Security

Please don't report security problems in a public issue. Use GitHub's private reporting instead: [report a vulnerability](https://github.com/bas3line/Components/security/advisories/new). It reaches [@bas3line](https://github.com/bas3line) directly.

The components draw pictures and play animations: they take no input beyond their props, store nothing and call no API. Reports about anything that could run someone else's code through a component, or about a dependency with a known hole, are especially welcome.

Fixes land on `main`.
